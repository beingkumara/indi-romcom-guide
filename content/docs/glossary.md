| Term | One-line meaning |
|---|---|
| **Code-mixing (CM)** | Using two languages inside one sentence. |
| **Romanized** | Written in English (Latin) letters instead of the language's own script. |
| **RCM** | Romanized code-mixing: both at once, e.g. *"Nenu exam ki prepare avvali"*. |
| **Register** | The style a text is written in. Here, "mixed and romanized" vs "plain English". |
| **Benchmark** | A fixed test set used to compare models. |
| **Zero-shot / 3-shot** | Prompting with no examples / with three worked examples. |
| **CMI** | Code-Mixing Index. In this paper, the share of English tokens replaced by Indian-language ones. |
| **CAT-0 … CAT-E** | The paper's word categories that decide what gets swapped at each level. |
| **RDR** | Register Defection Rate: share of replies that fall back to English. |
| **VCR** | Vocabulary Coverage Rate: share of swapped words the tokenizer holds as whole tokens. |
| **PG** | Performance Gap: English accuracy minus mixed accuracy. |
| **ChrF** | Automatic score of character overlap between two texts. |
| **Cohen's κ** | Agreement between two raters, corrected for chance. 0 = chance level, 1 = perfect. |
| **Wilcoxon / Bonferroni** | A paired significance test / a correction for running many tests. |
| **NLI** | Natural Language Inference: does sentence B follow from, contradict, or say nothing about sentence A? |
| **GSM8K** | A standard set of grade-school math word problems. |
| **Super-NaturalInstructions** | A large collection of NLP tasks phrased as instructions. |
| **IndicXTREME** | AI4Bharat's benchmark that includes IndicSentiment and IndicXParaphrase. |
| **IndicAlign / Toxic Matrix** | AI4Bharat instruction data; Toxic Matrix holds harmful prompts with refusals. |
| **Aksharantar / IndicXlit** | AI4Bharat's transliteration data and model for Indian languages. |
| **Aksharamukha** | A rule-based converter between scripts and romanization schemes. |
| **LoRA / QLoRA** | Cheap fine-tuning by training small add-on matrices; QLoRA does this on a 4-bit model. |
| **SOV** | Subject-Object-Verb word order, used by Telugu, Tamil, Hindi and the other benchmark languages. |
| **Agglutinative** | Building words by stacking suffixes, as in Telugu and Tamil. |
